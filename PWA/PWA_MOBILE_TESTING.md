# Testing Multimeter Detection PWA on Mobile Devices

To test this Progressive Web App (PWA) on your mobile phone, you must satisfy two requirements:
1. **Network Connectivity**: Your phone must be able to reach your computer's local port.
2. **Secure Context (HTTPS)**: Browsers require HTTPS (or `localhost`) to register Service Workers, enable offline support, and allow PWA installation ("Add to Home Screen").

Here are the step-by-step methods to run and test the app on mobile:

---

## Method 1: Secure Tunnel (Recommended - Easiest & Works Everywhere)

This is the easiest method. It uses a secure tunnel (like `localtunnel` or `ngrok`) to expose your local server over a public HTTPS link. Since it uses HTTPS, service workers register correctly and PWA installation works instantly on both iOS and Android.

1. **Start the local Vite dev server** on your computer:
   ```bash
   cd E:\2026_kazam\CV_mini3_3_screen_detection\PWA
   npm run dev
   ```
   *(By default, this runs on `http://localhost:5173`)*

2. **Expose the port using a tunnel** (run this in a new terminal window):
   ```bash
   npx localtunnel --port 5173
   ```
   *Alternative if localtunnel is slow/unavailable:*
   ```bash
   # Using pinggy
   ssh -p 443 -R0:localhost:5173 qr@pinggy.io
   ```
   *Or using ngrok:*
   ```bash
   ngrok http 5173
   ```

3. **Open the HTTPS URL** generated by the tunnel on your phone.
4. **Install as PWA**:
   - **iOS Safari**: Tap the **Share** button (box with up arrow) -> scroll down -> tap **Add to Home Screen**.
   - **Android Chrome**: Tap the three dots menu -> tap **Add to Home screen** or **Install app**.

---

## Method 2: Local Network (LAN) sharing

If your phone and computer are on the same Wi-Fi network, you can access the server directly, but you will need to bypass HTTPS security limits.

1. **Start Vite with the host flag** to expose it to the local network:
   ```bash
   cd E:\2026_kazam\CV_mini3_3_screen_detection\PWA
   npm run dev -- --host
   ```
   Vite will print your local IP, for example:
   `➜  Network: http://192.168.1.15:5173/`

2. **Access on Mobile**: Open `http://<your-computer-ip>:5173` in your mobile browser.

3. **PWA Setup (Secure Context Bypass)**:
   Because this is an `http://` address (not `localhost` or `https`), browsers will block service workers by default.

   - **Android Chrome**:
     1. Open Chrome on your phone and go to `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
     2. Enable the flag.
     3. Add your local URL (e.g. `http://192.168.1.15:5173`) to the text area.
     4. Relaunch Chrome. Now the service worker will register and you can install the PWA.
   - **iOS Safari**:
     - Bypassing secure context is not easily possible in mobile Safari over HTTP. Use **Method 1** instead.

---

## Method 3: Production Build & Hosting (Best for shareable links)

To test a production-optimized build of the PWA on a free static host (like Netlify, Vercel, or GitHub Pages):

1. **Build the production assets**:
   ```bash
   npm run build
   ```
   This compiles and places the static files into `PWA/dist/`.

2. **Deploy to Vercel/Netlify**:
   - Install Vercel CLI: `npm install -g vercel`
   - Run `vercel` in the `PWA` folder and select the `dist` directory for deployment.
   - Vercel will give you a public, SSL-secured `https://*.vercel.app` link that you can open and install on any phone.
